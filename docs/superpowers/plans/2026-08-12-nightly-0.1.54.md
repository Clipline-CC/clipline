# Nightly 0.1.54 Release

> **For agentic workers:** Execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking and remain unticked by repository convention.

**Goal:** Publish the merged waiting-update rail button and library context-menu Select as
signed-updater Nightly 0.1.54.

**Release-worthy user-visible changes since 0.1.53:**

- A button above Settings lights up when a Nightly update is waiting, so a Clipline left running
  for days still shows that a build shipped. A native poll checks about 30 seconds after launch,
  then every ten minutes, and stays silent (no mid-game modal). Launch and Settings checks still
  open the existing update dialog, which now warns that install stops recording and clears the
  replay buffer.
- Library clip right-click has **Select**. It turns on select-multiple and selects the clip that
  was right-clicked. Cloud clips and set-play rows keep their existing menus.
