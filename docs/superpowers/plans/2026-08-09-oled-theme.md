# OLED Theme Plan

## Goal

Add a true-black OLED theme that minimizes large illuminated areas while preserving clear controls, recording states, and clip-kind distinctions.

## Tasks

1. Add failing settings and UI-contract coverage for the OLED value, selector option, true-black base, palette completeness, logo tint, and distinct clip-kind colors.
2. Add the OLED enum/selector value and define it entirely through the existing CSS theme tokens.
3. Update the design and handoff docs, run workspace tests and clean-cache clippy, then relaunch Clipline for visual verification.
