# Nightly 1.0.3 Release

> **For agentic workers:** Execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking and remain unticked by repository convention.

**Goal:** Publish ordered clip groups, favorites-aware storage cleanup, library deletion fixes, and
the faster verified Windows release pipeline as signed-updater Nightly 1.0.3.

**Release-worthy user-visible changes since 1.0.2:**

- Library groups can arrange clips into durable playlists and build reusable ordered compilation
  videos with mixed audio, drag/keyboard reordering, filtering, playback, sharing, and Cloud state.
- Favorites are available from clip cards and filters; quota auto-delete preserves them and removes
  lower-value replay clips before sessions and trims.
- Deleting the last clip removes empty session folders without leaving ghost library cards, while
  preserving unrelated files and surfacing cleanup failures.
- The Windows Nightly workflow installs the pinned Tauri CLI directly and skips ineffective cache
  saves, cutting release time without weakening signing or public-asset verification.
