toggle labels as signed-updater Nightly 0.1.56.

- Capturing a new hotkey no longer triggers live capture/recording binds, and capture pause stays
  aligned with window focus.

- The player header shows the clip file name instead of the full path.
- The clip toggle button labels its two states Clip and Close.
