# Nightly 0.1.45 Release

> **For agentic workers:** Execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking and remain unticked by repository convention.

**Goal:** Publish PR #138's review-playback flicker fix as the signed-updater Nightly 0.1.45
release, with the currently offered WebView2 Fixed Version runtime.

**Release-worthy user-visible change since 0.1.44:**

- New recordings no longer contain unpresentable one-tick video edit-list gaps that WebView2 can
  expose as a brief flash of the first frame during review playback. Real frame-sized video gaps,
  leading gaps, and every audio gap remain unchanged.
