> **For agentic workers:** Execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking and remain unticked by repository convention.

**Goal:** Publish the update-channel and tray/library fixes that landed after Stable 1.0.0 as
signed-updater Nightly 1.0.1.

**Release-worthy user-visible changes since 1.0.0:**

- The update dialog installs exactly the update it shows instead of a later rail payload.
- The selected update channel is checked before settings finish saving, so a channel switch
  takes effect immediately.
- Left-clicking the tray icon opens the app; the menu stays on right click.
- Reveal-in-Explorer selects the revealed clip in the library view.
