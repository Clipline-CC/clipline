**Goal:** Publish the merged League Replay gate, Library LoL Type search tokens, and header stats
wrap as signed-updater Nightly 0.1.55.

**Release-worthy user-visible changes since 0.1.54:**

- League client replays (`.rofl` on `League of Legends.exe`) are their own recordable game type.
  Settings → League → Record game types includes **Replay** (default on). The automatic gate
  prefers that command-line signal over LCU queue id, so a ranked replay is skipped or recorded as
  Replay rather than Ranked Solo/Duo.
- Library search no longer has a Game type dropdown. Type or choose **`LoL Type:`** in the search
  bar (Discord-style chip + suggestion list) to filter Ranked, ARAM, Replay, and the rest.
- Library header clip count and storage figures wrap as whole phrases (`18 of 18` /
  `25.2 GB / 100 GB`) instead of splitting mid-token when the window is narrow.
