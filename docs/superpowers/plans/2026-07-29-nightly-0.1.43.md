# Nightly 0.1.43 Release

> **For agentic workers:** Execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking and remain unticked by repository convention.

**Goal:** Publish the merged sharing and cloud-upload reliability work as the signed-updater
Nightly 0.1.43 release: PR #130 (shareable H.264/AAC clipboard exports), PR #131 (stable review
state and feedback after cloud uploads), and PR #105 (canonical public Cloud share URLs).

**Release-worthy user-visible changes since 0.1.42:**

- Normal Copy now creates a broadly compatible H.264/AAC-LC MP4, preserving selected audio and
  transcoding HEVC/AV1 through a proven H.264 encoder when needed; Shift+click copies the untouched
  original file (#130).
- Cloud upload completion no longer looks like a review-page crash when equivalent Windows path
  spellings are reconciled. Successful `Delete local after upload` actions explain the return to
  Library, including when the upload finished in the background, and cleanup failures remain
  visible (#131).
- Public and unlisted Cloud clips copy the API-provided canonical public URL so chat clients can
  unfurl clip metadata. Private clips remain available to their owner without exposing a share-link
  action (#105).
