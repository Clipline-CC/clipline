# Nightly 0.1.46 Release

> **For agentic workers:** Execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking and remain unticked by repository convention.

**Goal:** Publish the merged onboarding, slim-core, sparse-capture, Library workflow, and
non-destructive quota work as the signed-updater Nightly 0.1.46 soak build.

**Release-worthy user-visible changes since 0.1.45:**

- First-run setup now offers a complete manual wizard and a one-click F6 / 720p60 / 30-second
  recommended configuration with automatic game detection.
- Saved-media quotas never delete clips automatically; recording pauses with recovery actions
  until space is made or the quota is raised.
- Clipboard exports cancel with the app, long clips copy the original by default, Library cards
  expose both copy modes, and Cloud uploads show activity and completion feedback.
- The regular installer no longer bundles FFmpeg, installs it on demand when optional features need
  it, and releases WebView2 resources while Clipline is in the tray.
- Sparse desktop capture no longer trips the missing-keyframe watchdog after static periods.
