# Nightly 0.1.47 Release

> **For agentic workers:** Execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking and remain unticked by repository convention.

**Goal:** Publish the merged recording-control, game-aware Library, capture-state, and Cloud
handoff improvements as signed-updater Nightly 0.1.47.

**Release-worthy user-visible changes since 0.1.46:**

- Start or stop a saved full-session recording from Clipline or either of two optional global
  hotkeys, independently of the rolling replay buffer.
- The left rail now shows the actual monitor, region, or game being captured and distinguishes
  active capture, waiting for a game, buffer readiness, and full-session recording honestly.
- League recordings carry their game type when the local League client reports it, and the
  Library can filter Ranked Solo/Duo, Ranked Flex, Normal, ARAM, Arena, Custom, and other modes.
- Completed Cloud uploads copy their share link in the background and move a deleted local clip's
  matching Review view to the Cloud Library without disrupting another clip.
- Large clip sizes display in GB, custom-game rules no longer duplicate or override one another,
  and mid-stream full-session recordings keep correct audio timing.
