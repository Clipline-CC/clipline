# Nightly 0.1.53 Release

> **For agentic workers:** Execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking and remain unticked by repository convention.

**Goal:** Publish the merged user bookmark hotkey as signed-updater Nightly 0.1.53.

**Release-worthy user-visible changes since 0.1.52:**

- A bookmark hotkey (**F7** by default) marks the current moment on the recording timeline while
  recording, in both replay-buffer and full-session modes. A short two-tone blip confirms the press.
- Bookmarks show up on the review timeline alongside game markers — pins, overview ticks, the
  marker count, prev/next-marker navigation, drag snapping, and the library "marked" filter — and
  appear even on clips with no detected game.
- A bookmark dropped before Save Replay rides into the saved clip.
- The F7 default is not applied when it would collide with an existing binding, and a bookmark
  hotkey the user clears stays unbound.
