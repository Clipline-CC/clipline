# Purple Theme Plan

## Goal

Add a third, deep-purple Clipline theme that previews immediately, persists through the existing settings transaction, and leaves Booth as the default.

## Tasks

1. Add failing settings and UI-contract coverage for the new theme value, dropdown option, preview wiring, and complete CSS token palette.
2. Add the Purple settings enum variant and dropdown option, then generalize the existing theme attribute helper.
3. Define the Purple palette entirely through the existing CSS custom properties.
4. Update the design and handoff docs, run workspace tests and clippy, then relaunch Clipline for visual verification.
