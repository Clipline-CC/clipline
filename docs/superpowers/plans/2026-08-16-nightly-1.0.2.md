# Nightly 1.0.2 Release

> **For agentic workers:** Execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking and remain unticked by repository convention.

**Goal:** Publish the uninstaller, storage-quota, update-channel-default, and cloud-UI fixes that
landed after Nightly 1.0.1 as signed-updater Nightly 1.0.2.

**Release-worthy user-visible changes since 1.0.1:**

- The NSIS uninstaller removes Clipline's app residue — managed media, replay ownership records,
  and Windows credential entries — while preserving unknown replay files and validating replay
  ownership before deletion.
- Storage quota totals no longer count recording sidecars, and Settings can delete all managed
  media at once.
- Fresh installs start on the update channel their package tracks (Nightly installers default to
  Nightly, Stable installers to Stable); saved choices and legacy Nightly settings are kept.
- The update dialog links the official changelog.
- Cloud actions are hidden while signed out.
