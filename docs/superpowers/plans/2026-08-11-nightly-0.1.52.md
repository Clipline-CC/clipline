> **For agentic workers:** Execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking and remain unticked by repository convention.

**Goal:** Publish the merged League recording controls, review polish, and recording reliability
fixes as signed-updater Nightly 0.1.52.

**Release-worthy user-visible changes since 0.1.51:**

- League users can choose which game types record automatically, including Ranked, Normal, ARAM,
  Arena, Custom, and other/unknown queues.
- Storage-full actions work correctly instead of surfacing a script error.
- Clipline avoids hardware encoders that advertise support but fail when recording, improving
  reliability on affected Intel-powered Windows PCs.
- Trim playback stops exactly at the selected end point.
- Hexflash uses the Flash icon in clip details, including older clips, and Herald takedowns use the
  correct Herald artwork in the match event timeline.
