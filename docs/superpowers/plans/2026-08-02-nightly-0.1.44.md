# Nightly 0.1.44 Release

> **For agentic workers:** Execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking and remain unticked by repository convention.

**Goal:** Publish PR #133's support-report-driven reliability fixes as the signed-updater Nightly
0.1.44 release.

**Release-worthy user-visible changes since 0.1.43:**

- Cloud uploads and normal Copy exports can mix output and microphone tracks whose starts are
  offset by less than one Opus packet without producing overlapping or backward MP4 timestamps.
- Selected-track mixing consumes each track's own pre-skip, tolerates only the supported one-tick
  duration quantization, preserves long timeline gaps, and rejects corrupt decoded/container Opus
  duration mismatches before cropping or padding audio.
- Support-report logs remain valid JSONL after Windows paths inside JSON strings are redacted.
