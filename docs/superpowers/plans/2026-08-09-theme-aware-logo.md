# Theme-Aware Logo Plan

## Goal

Tint Clipline's in-app logo to match the selected color theme without duplicating the SVG asset.

## Tasks

1. Add a UI contract for a shared logo filter token in every theme palette.
2. Apply the token to all in-app uses of the Clipline SVG.
3. Run the focused UI contract, workspace tests, and clippy; then relaunch Clipline.
